# Python Inventory Reorder Assessment

## Description
This project reads inventory data from a CSV file, checks each item's current quantity against its reorder threshold, and identifies items that need restocking.

## Files
- main.py – Python script
- stock.csv – Inventory data

## How to Run
1. Make sure Python is installed.
2. Place main.py and stock.csv in the same folder.
3. Run:
   bash
   python main.py
   

## Output
The program displays the items that need to be reordered based on the inventory thresholds.
